## Wave 5: broadening and platform

Contracts T19 to T24 set for later tasks, and follow-ups whose design belongs to the task that first needs them.

- **Pending aws-chunked trailers** (T36, T39). Handlers see only `smithy.Body`, whose `Trailer(name) (string, bool)` cannot tell a trailer still pending (before EOF) from an absent one; `restbind.Body.Deferred` has the three states, but `internal/service` cannot import `restbind`. Replace `Trailer` with a three-state answer (a sum of `Pending`, `Absent` and `Sent{Value}`), implement it in `restbind.Body` (dropping `Deferred` and `PendingError`), `edge.requestBody`, `gen.TextBody`, the generated `exampleBody` and the test bodies, and assert `Pending` through the interface in `TestTrailerBoundMemberResolvesAtEOF`. Left for the first handler that reads a trailer, which designs the call site.
- **Rejected rpcv2Cbor requests** (T31). The edge has no claim that ends routing and answers with the claiming codec's `EncodeError`, so a request the rpcv2Cbor codec rejects (not a POST, a wrong Content-Type, `X-Amzn-Target`) maps to `Declined` and falls through to rules 6 to 8; one with `X-Amz-Target` gets the Unclaimed codec's awsJson body, which a CBOR client cannot decode (`wire-cbor.md 5.2`). Add an `edge.Claim` variant for it and update `rpcv2cbor/doc.go`'s Rejected paragraph; CloudWatch is the first rpcv2Cbor service.
- **awsQuery error envelope on the descriptor** (T26, T30, T31). `errorEnvelopeOf` in `internal/protocol/awsquery/codec.go` holds the `ErrorResponse` namespace and the empty `Detail` by service id (CloudWatch, IAM, SQS), because no `dev.understudy` trait and no `registry.Service` field carries them. Moving them into the overlays needs a new trait, which is an ADR 0002 amendment.
- **Version-less legacy SQS Query requests** (T26). The awsQuery codec finds the service by `Version` alone, so the API reference's own SendMessage example, which has none, is declined (`TestSQSDocumentedFormWithoutVersionIsDeclined`). If a recording shows SQS accepting such requests, the edge can confirm the service from the SigV4 signing name on a queue path.
- **SNS dead letters** (T27, T35). `delivery.Request.DLQ` names the queue only, so the outbox dead-letters the target's own payload; for an SNS-to-Lambda subscription AWS sends the SQS-style notification envelope (LocalStack `test_redrive_policy_lambda_subscription`), not the Lambda `Records` event. Replace `DLQ` with a `*DeadLetter{Queue, Body, Attributes, GroupID, DedupID}` that SNS builds with `service/sns/envelope`; the outbox sends it verbatim plus the EventBridge attributes it adds, and `TestSNSToLambda` asserts the envelope body.
- **Delivery attempts in the source trace** (T35, T40). `kernel.Invoke` takes its parent from the timer `Call`, whose fields are private to the kernel, so an outbox attempt's target call joins the `TimerFired` trace instead of the source call's. Let a call resume a stored cause (for example a `Cause` on `kernel.Target`), pass `Entry.Cause` from the attempt, and test that the target sees the source trace, so PutObject, notification, SendMessage, ESM and Invoke stay in one trace.
- **SNS FIFO publish order** (T35). The kernel calls `Deliver` after the source cell unlocks, so two publishes to one message group can reach `Outbox.Enqueue` in the opposite order to their commits. Serialize per group in SNS, or have the kernel deliver in commit order.
- **Scoped reset of DynamoDB data** (T37). A reset by account or region that selects DynamoDB answers `unavailable` until the service implements `admin.LateResetter` (`ResetLate`: `DeleteTable` per scope, ARCHITECTURE.md 13).
- **Docker and DynamoDB Local health** (T33, T38). `admin.Health.Docker` and `DynamoDBLocal` stay absent: `serveradmin.Options` has no source for them, so the first service that runs on each adds the hook.
- **Periodic `--persist` checkpoint** (T44). It takes the lock `serveradmin.Handler` holds over reset, snapshot save and load (through a method the handler exposes), or a checkpoint can cut between a reset's gate and its late data.
- **Admin token and container exposure for `serve`** (T44). `server.Config.AdminToken` lets a non-loopback listener serve the admin API behind a bearer token, but `understudy serve` has no setting for it, so the CLI still listens only on loopback; read it from the environment or the config file rather than a flag, which process listings show. `Exposed{ContainerPublished}` (ARCHITECTURE.md 20) arrives with the topology wiring; `server.ListenError` names both options.
- **CloudWatch query-mode statuses** (T31). Only `ResourceNotFound` carries `statusOverride` 400 (LocalStack snapshot evidence). `DashboardNotFoundError` and `ResourceNotFoundException` may need the same once their JSON status is recorded.
- **S3 POST on an object without `uploadId`** (T39). Route rows require query and header presence only where needed to tell rows apart, so such a POST reaches `CompleteMultipartUpload` and fails validation rather than finding no route. A recording decides; a `routeOverrides` entry in `codegen/services/s3.json` can require `uploadId`.
