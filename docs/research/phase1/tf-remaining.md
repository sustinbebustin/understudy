# Terraform AWS provider call sequences: remaining phase 1 resources and data sources

Research input for understudy phase 1, closing gap G6. Scope: the exact API traffic `hashicorp/terraform-provider-aws` v6.68.0 under Terraform 1.16.0 generates for `aws_iam_user`, `aws_iam_access_key`, `aws_iam_user_policy`, `aws_iam_user_policy_attachment`, `aws_iam_instance_profile`, `aws_lambda_alias`, `aws_lambda_function_event_invoke_config`, `aws_lambda_provisioned_concurrency_config`, the `reserved_concurrent_executions` argument of `aws_lambda_function`, `aws_secretsmanager_secret_policy`, `aws_kms_key_policy`, `aws_cloudwatch_log_stream`, the `aws_s3_object` family (`aws_s3_object`, `aws_s3_object_copy`, deprecated `aws_s3_bucket_object`), `aws_sns_topic_subscription` with `lambda` and `sqs` protocols, and the data sources `aws_caller_identity`, `aws_region`, `aws_partition`, `aws_iam_policy_document`, `aws_iam_role`, `aws_kms_alias`, `aws_kms_key`, `aws_secretsmanager_secret`, `aws_secretsmanager_secret_version`, `aws_sqs_queue`, `aws_s3_bucket`, `aws_dynamodb_table`, `aws_lambda_function`. Per create, read, update and delete: calls, waiters and minimum wall time, response fields dereferenced, errors keyed on, perpetual-diff and crash traps. Companion files: [tf-compute.md](tf-compute.md), [tf-messaging.md](tf-messaging.md), [tf-storage.md](tf-storage.md).

Conventions:
- SRC: provider source at tag `v6.68.0`, linked with line ranges. Links read `.../blob/v6.68.0/internal/service/<pkg>/<file>#L..`; the base is `https://github.com/hashicorp/terraform-provider-aws`.
- OBS: observed by running the released provider binary against a logging reverse proxy in front of a stand-in server (section 1). Request shapes in OBS are the provider's and are authoritative; the stand-in's answers are not evidence of AWS behavior.
- MODEL: the Smithy model at `aws/api-models-aws` commit `1cfdfb4bb9ea858e65623e66d73af04bec353201`, the pin used by the other tf-* files.
- UNVERIFIED marks anything I could not confirm in a primary source (almost always real-AWS runtime behavior).
- Experiments named `x:<name>` in section 11 are controlled deviations of the stand-in (one response field changed or removed) and show what the provider does when the server is wrong.

## 1. How the OBS evidence was produced

1. `terraform init` against a local filesystem mirror of the registry package for `hashicorp/aws` 6.68.0, working files in the session scratchpad outside the repo; no network except the one-time registry download.
2. Stand-in: moto 5.2.3 `moto_server` on `127.0.0.1` ([moto 5.2.3](https://pypi.org/project/moto/5.2.3/)), used only as a responder. moto does not implement `PutProvisionedConcurrencyConfig` and its event-invoke-config store ignores the `Qualifier`, so a small hook in the proxy answered those two route families from memory (marked `STUB` in the logs): `PUT|GET|DELETE /2019-09-30/functions/{fn}/provisioned-concurrency?Qualifier=` and `PUT|POST|GET|DELETE /2019-09-25/functions/{fn}/event-invoke-config[?Qualifier=]`. Shapes follow the Smithy model ([lambda model](https://github.com/aws/api-models-aws/blob/1cfdfb4bb9ea858e65623e66d73af04bec353201/models/lambda/service/2015-03-31/lambda-2015-03-31.json)).
3. A ~100-line stdlib Python reverse proxy in front logged every request and response as JSONL (method, path, `X-Amz-Target`, SigV4 scope, headers, bodies, status, latency). It listens dual-stack because the endpoint must be `http://localhost:<port>`: S3 Control prefixes the account id to the authority (`123456789012.localhost`) and `*.localhost` resolves to `::1` here (see [tf-storage.md 1.1](tf-storage.md)).
4. Provider block: static `test`/`test` credentials, region `us-east-1`, `s3_use_path_style = true`, `skip_metadata_api_check = true`, and **no `skip_*` flags**; endpoint through `AWS_ENDPOINT_URL` only.
5. One configuration of 37 resources and 17 data sources (5 of them `aws_iam_policy_document`) exercising every item in scope (an IAM user with path and tags, access key, inline and managed user policies, attachment, instance profile with a role; a published Lambda function with reserved concurrency, alias, two event invoke configs, provisioned concurrency, SNS permission; SQS queue, SNS topic, `sqs` and `lambda` subscriptions; KMS key, alias, key policy; secret, version, secret policy; log group and stream; two buckets, one versioned, with objects from `content`, `content_base64`, small and 12 MiB `source`, `kms_key_id`, copy; DynamoDB table; all data sources). Phases, each with `-parallelism=1` so each resource's calls are contiguous in the log: `apply` (201 API calls), `plan -detailed-exitcode` (121 calls, exit 0), update `apply` changing one attribute of 17 resources, 16 in place and 1 replaced (184 calls), `plan` (121 calls, exit 0), `destroy` (199 calls). The `plan` after each apply reported "No changes" with the stand-in conformed as described; every deviation below is a separate run of the same configuration or a minimal one-resource configuration.
6. Wall times are Terraform's own "complete after" figures from the same runs.

## 3. IAM

### 3.1 `aws_iam_user`

Timeouts: no `Timeouts` block (default 20 min, [plugin-sdk resource_data.go](https://github.com/hashicorp/terraform-plugin-sdk/blob/v2.40.1/helper/schema/resource_data.go#L552-L560)); IAM propagation retries use 2 min ([iam consts.go L16](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/consts.go#L16)).

**Create** ([user.go L96-L143](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user.go#L96-L143)):
1. `CreateUser`, retried up to 2 min on `ConcurrentModificationException` ([L732-L756](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user.go#L732-L756)). OBS body: `Action=CreateUser&Path=%2Fsvc%2F&Tags.member.1.Key=env&Tags.member.1.Value=test&UserName=g6-user`. `Path` is always sent (default `/`); `PermissionsBoundary` only when set; `Tags.member.N` only when non-empty (tag order is a Go map iteration, random). The response must carry `User.UserName` (empty name is an error; a missing `User` element dereferences nil at [L751](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user.go#L751), UNVERIFIED by experiment).
2. Resource ID = `User.UserName`. Then Read.

**Read** ([L145-L172](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user.go#L145-L172), flatten [L758-L768](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user.go#L758-L768)): `GetUser {UserName}` retried while not found for a new resource (2 min); `NoSuchEntity` is not found. If `User.Arn` is not a parseable ARN the provider waits (`Delay` 5 s, poll 1 s, 5 consecutive hits) re-calling `GetUser` ([L314-L337](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user.go#L314-L337)); a valid ARN skips this at once. Fields: `Arn`, `UserName`, `Path`, `PermissionsBoundary.PermissionsBoundaryArn` (nil means unset), `UserId` (`unique_id`), `Tags` (set from this response; **no `ListUserTags` call**, OBS).

**Update** ([L174-L220](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user.go#L174-L220)): tags first via the transparent-tagging interceptor, then `UpdateUser {UserName, NewUserName, NewPath}` only when name or path changed, `PutUserPermissionsBoundary` / `DeleteUserPermissionsBoundary` on boundary change, then Read. OBS tag change `{a=1,b=2}` -> `{a=3}`: `UntagUser {TagKeys.member.1=b}` then `TagUser {Tags.member.1.Key=a, Value=3}` then `GetUser`; no `UpdateUser`, no `ListUserTags`. Untag runs before tag.

**Delete** ([L222-L284](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user.go#L222-L284)): `ListGroupsForUser {UserName}` **always** (paginated; `RemoveUserFromGroup` per group), then `DeleteUser`, retried 2 min on `DeleteConflictException`; `NoSuchEntity` is success. The extra cleanup calls (`DeleteUserPolicy`, detach, access keys, SSH keys, MFA, login profile, signing certificates, service-specific credentials) run only when `force_destroy = true` ([L234-L264](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user.go#L234-L264)). OBS destroy: `ListGroupsForUser`, `DeleteUser`. This corrects [iam-sts-kms.md 3.1](iam-sts-kms.md) (section 13).

Model facts: `User.CreateDate` and `User.Arn` are required members ([MODEL IAM User](https://github.com/aws/api-models-aws/blob/1cfdfb4bb9ea858e65623e66d73af04bec353201/models/iam/service/2010-05-08/iam-2010-05-08.json)). `NoSuchEntityException` is wire code `NoSuchEntity` HTTP 404; `ConcurrentModification`, `DeleteConflict`, `EntityAlreadyExists`, `LimitExceeded` are 409; `InvalidInput` 400; `ServiceFailure` 500 (same MODEL, `awsQueryError` traits).

Perpetual-diff traps: none observed with a conforming server. `path` is Optional with default `/` and is read from `User.Path`; the ARN must embed the path (`arn:aws:iam::<acct>:user/svc/g6-user`, OBS) because the provider stores it verbatim.

### 3.2 `aws_iam_access_key`

**Create** ([access_key.go L127-L203](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/access_key.go#L127-L203)): `CreateAccessKey {UserName}` (OBS `Action=CreateAccessKey&UserName=g6-user`), no retry. The resource ID is `AccessKey.AccessKeyId`; `AccessKey.SecretAccessKey` must be non-nil or the create fails ([L144](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/access_key.go#L144)). The provider computes `ses_smtp_password_v4` locally from the secret and region and stores `secret` (sensitive) from this one response: the secret is **never re-read**. If `status = "Inactive"` is configured, a second call `UpdateAccessKey {AccessKeyId, Status=Inactive, UserName}` follows ([L179-L192](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/access_key.go#L179-L192)). No Read is issued after create: state comes from the `CreateAccessKey` response (`CreateDate`, `Status`, `UserName`).

**Read** ([L205-L237](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/access_key.go#L205-L237), finders [L285-L331](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/access_key.go#L285-L331)): `ListAccessKeys {UserName}` (paginated, OBS `Action=ListAccessKeys&UserName=g6-user`), filtered to exactly one entry whose `AccessKeyId` equals the ID (`AssertSingleValueResult`; entries that are all-zero are skipped). `NoSuchEntity` is not found. **`GetAccessKeyLastUsed` is not part of read: it runs only in the import handler** ([L50-L72](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/access_key.go#L50-L72)). Fields from the entry: `AccessKeyId`, `CreateDate` (guarded for nil), `Status`, `UserName`.

**Update** ([L239-L250](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/access_key.go#L239-L250)): `UpdateAccessKey {AccessKeyId, Status, UserName}` when `status` changed, then Read (OBS: `UpdateAccessKey` then `ListAccessKeys`). **Delete** ([L252-L270](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/access_key.go#L252-L270)): `DeleteAccessKey {AccessKeyId, UserName}`, `NoSuchEntity` is success.

Perpetual-diff trap (OBS `x:ak_nouser`): `d.Set("user", key.UserName)` on read. `user` is `Required` and `ForceNew`; if `ListAccessKeys` omits `UserName` in its members the state value becomes null and the next plan is `-/+ aws_iam_access_key must be replaced` (`+ user = "g6-user" # forces replacement`), rotating the key on every apply. `ListAccessKeys` entries must always carry `UserName`, `AccessKeyId`, `Status`, `CreateDate`.

The access key ID format and the account encoded in it are covered in [iam-sts-kms.md 2.1-2.2](iam-sts-kms.md).

### 3.3 `aws_iam_user_policy`

**Create/Update share one handler** ([user_policy.go L81-L116](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user_policy.go#L81-L116)): `PutUserPolicy {UserName, PolicyName, PolicyDocument}`, no retry. OBS document form: `{"Version":"2012-10-17","Statement":[...]}` (`Version` first: the legacy normalizer, unlike the sorted-key form used for role and KMS policies). For a new resource the ID `<user>:<policy>` is set and `GetUserPolicy` is retried until found, then Read, so two `GetUserPolicy` calls (OBS). **Read** ([L118-L163](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user_policy.go#L118-L163)): `GetUserPolicy {UserName, PolicyName}`; `PolicyDocument` is required in the response and is run through `url.QueryUnescape` ([L146-L152](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user_policy.go#L146-L152)). The model says user policies from this operation are "URL-encoded compliant with RFC 3986" ([MODEL GetUserPolicy docs](https://github.com/aws/api-models-aws/blob/1cfdfb4bb9ea858e65623e66d73af04bec353201/models/iam/service/2010-05-08/iam-2010-05-08.json)). **Delete**: `DeleteUserPolicy`, `NoSuchEntity` is success ([L165-L190](https://github.com/hashicorp/terraform-provider-aws/blob/v6.68.0/internal/service/iam/user_policy.go#L165-L190)). Update issues `PutUserPolicy` then Read (one `GetUserPolicy`), no wait.

Perpetual-diff trap (OBS `x:decode_policy`): a server that returns the document **unencoded** works until the document contains `+`: a condition value `a+b` came back as `a b` and every later plan showed `~ "aws:username" = "a b" -> "a+b"` (exit 2). `%` not followed by two hex digits would fail the read outright (`invalid URL escape`, derived from the Go function, not run). Always percent-encode (RFC 3986, `+` as `%2B`, as [tf-compute.md section 10 item 9](tf-compute.md) already requires for roles).

Behaviors not previously required:
1. **Crash-on-missing fields** (the server must always return): IAM `CreateDate` on `GetInstanceProfile` and `GetRole`; Secrets Manager `CreatedDate` and `LastChangedDate` on `DescribeSecret` and `CreatedDate` on `GetSecretValue`. Omission panics the whole provider process (register rows 1-4).
2. **Instance profile 5 s floor on create and on every update**, including tags-only; `GetInstanceProfile` must return a parseable `Arn` and the attached role as a full `Role` with `CreateDate`.
3. **Provisioned concurrency**: 202 on put, `READY` with `Allocated` = `Requested` = `Available`, `ProvisionedConcurrencyConfigNotFoundException` 404 with `message`; 5 s provider floor.
4. **Event invoke config storage keyed by (function, qualifier)**, `MaximumEventAgeInSeconds` omitted when unset, `MaximumRetryAttempts` echoed including 0.
5. **`GetAlias`**: omit `RoutingConfig` unless weights exist; `CreateAlias`/`UpdateAlias` receive `Description:""` and `RoutingConfig:{}` and must treat the empty object as "no routing".
6. **Reserved concurrency 0** must read back as present `0`; unset must read back as absent.
7. **`GetUserPolicy` must percent-encode** the document (`+` as `%2B`); **`ListAccessKeys` entries must carry `UserName`**.
8. **KMS key policy**: store verbatim and return an equivalent document immediately (no injected `Id`); 5-hit wait costs 4 s for each put; delete puts the default policy with `Id: "default"`.
